# Projeto HasDevNotes — Biblioteca Pessoal de Cheat Sheets

## Visão geral

Quero desenvolver uma aplicação web chamada **HasDevNotes**, uma biblioteca pessoal de Cheat Sheets voltada para programação e desenvolvimento de software.

O objetivo é centralizar tudo o que aprendo e utilizo na programação em uma única plataforma, oferecendo consultas rápidas a conceitos, sintaxes, comandos e exemplos de código.

O projeto deve ser escalável, organizado e visualmente moderno, mas começar com uma implementação simples e funcional.

## Público-alvo

Inicialmente, eu mesmo. Sou estudante de desenvolvimento de software e quero utilizar a plataforma durante meus estudos e projetos.

No futuro, a aplicação poderá ser utilizada por outros desenvolvedores.

## Identidade visual

- Interface moderna e minimalista, com aparência de ferramenta profissional de desenvolvimento.
- Tema escuro como padrão.
- Barra lateral para navegar entre tecnologias e categorias.
- Cards organizados e fáceis de ler.
- Destaque de sintaxe nos exemplos de código.
- Tipografia monoespaçada nas áreas de código.
- Layout responsivo para desktop, tablet e celular.
- Navegação rápida, com poucas distrações.

## Estrutura dos conteúdos

A aplicação deverá organizar as informações em três níveis:

1. **Tecnologia:** JavaScript, TypeScript, React, HTML, CSS, SQL, Git, Python etc.
2. **Categoria:** agrupamentos de assuntos dentro de cada tecnologia.
3. **Cheat Sheet:** conteúdo individual de consulta.

Cada Cheat Sheet deverá conter:

- Título.
- Descrição objetiva do conceito.
- Explicação de quando utilizar.
- Sintaxe principal.
- Exemplo de código.
- Resultado esperado, quando aplicável.
- Dicas, cuidados e erros comuns.
- Tags e conteúdos relacionados.

## Funcionalidades do MVP

1. Página inicial com visão geral da biblioteca.
2. Sidebar de navegação por tecnologias.
3. Categorias organizadas por assunto.
4. Sistema de busca global.
5. Exibição de Cheat Sheets em cards.
6. Visualização de exemplos com syntax highlighting.
7. Botão para copiar trechos de código.
8. Sistema de favoritos.
9. Criação, edição e exclusão de anotações pessoais.
10. Persistência local das anotações e preferências.
11. Interface responsiva.
12. Conteúdos iniciais de exemplo para validar a aplicação.

## Tecnologias

- React para a interface.
- TypeScript para desenvolvimento tipado.
- Vite como ferramenta de desenvolvimento.
- Tailwind CSS para estilização.
- Armazenamento local na versão inicial.
- Arquitetura preparada para futura integração com banco de dados.

## Funcionalidades futuras

- Login e contas de usuário.
- Sincronização de anotações entre dispositivos.
- Importação e exportação de conteúdos.
- Editor de Markdown.
- Assistente de IA para explicações.
- Exercícios de revisão.
- Histórico de consultas.
- Personalização de temas e layout.

## Princípios de desenvolvimento

A aplicação deverá priorizar velocidade, usabilidade, manutenção e organização do código.

Quero uma arquitetura baseada em componentes reutilizáveis, tipos bem definidos e separação entre interface, dados e regras de negócio.

É importante evitar complexidade desnecessária, especialmente na primeira versão.
